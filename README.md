## 🗡️ Synopsis & Story

Beneath Hyrule Castle, a cataclysmic gloom has broken the ancient millenia-old seal. **Demon King Ganondorf has reawakened in fury**, shattering the Master Sword into fractured embers and spilling crimson malice across the skies. In the chaos, Princess Zelda vanished into an enigmatic rift of sacred light, leaving behind only an ancient echo.

You awaken high in the heavens upon the **Great Sky Island**. The power of the ancient Zonai now pulses in your right arm. Leap from the Awakening Sanctuary, reclaim your strength, master the skies with your Paraglider, wield Ultrahand and weapon fusion, find Princess Zelda, and vanquish the Reawakened Malice!

## 🌟 Key Features

- **Native PC Performance**: Powered by modern Three.js & WebGL with 60+ FPS, cel-shaded anime aesthetic, atmospheric cloud fog, and Zonai glowing particle effects.
- **Great Sky Island Spawn**: Begin atop the high-altitude Awakening Sanctuary with the iconic diving ledge.
- **Dynamic Skydiving & Paraglider**: Freefall through the clouds with aerodynamic camera shifts, wind particles, and deploy the Paraglider with `[Space]`.
- **Stamina Wheel & Health System**: Green circular stamina wheel managing sprints, climbing, and aerial gliding. Full 5-heart TotK health container interface.
- **Ultrahand Ability (`[F]`)**: Telekinetically grab, rotate, and position ancient Zonai blocks, planks, and ruins in 3D space with a glowing emerald energy beam.
- **Weapon & Arrow Fusion (`[Q]`)**: Fuse materials (Fire Fruit, Bomb Flowers, Zonai Horns, Gloom Residue) to weapons and arrows to increase attack power and inflict elemental bursts.
- **Arsenal of Hyrule**:
  - **Weapons**: Decayed Master Sword, Reawakened Master Sword, Knight's Broadsword, Zonai Longsword, Gloom Katana.
  - **Bows & Shields**: Zonai Energy Bow, Royal Bow, Soldier's Bow, Hylian Shield, Zonai Shield.
  - **Elemental Staffs**: Ruby Fire Staff, Sapphire Frost Staff, Topaz Thunder Staff, Reawakened Malice Staff.
  - **Materials**: Fire Fruit, Ice Fruit, Bomb Flower, Zonai Energy Charge, Construct Blade Horn, Gloom Residue.
- **Enemies & Epic Boss Fight**:
  - **Zonai Soldier Constructs**: Patrol sky ruins armed with energy blades.
  - **Bokoblins**: Red horn monsters roaming lower islets.
  - **Demon King Ganondorf (Reawakened)**: Multi-phase boss encounter at the Sky Arena (Phase 1: Gloom Katana combos; Phase 2: Demonic gloom sorcery and crimson shockwaves with full TotK boss health bar).
- **Cinematic "crazy_link67 games" Splash Screen**: Custom animated Zonai rune ring, Triforce flare, and authentic startup chime.
- **Creators Acknowledgment**: Dedicated tribute honoring Shigeru Miyamoto, Eiji Aonuma, Hidemaro Fujibayashi, Koji Kondo, and the Nintendo EPD Zelda team.
- **GitHub Auto-Sync**: Built-in script (`npm run sync`) to automatically stage, commit, and push updates to `Crazy-Link67/zelda-ganandorf-reawakened`.

## 🎮 PC Controls

| Key / Action | Function |
| :--- | :--- |
| **W, A, S, D** | Move Link (Forward, Left, Backward, Right) |
| **Mouse Look** | Orbit 3rd-person camera / Aim |
| **Shift** | Sprint (consumes Stamina) / Skydiving fast dive |
| **Space** | Jump / Deploy or fold Paraglider in mid-air |
| **Left Click** | Attack / Sword slash combo / Fire Arrow when aiming |
| **Right Click** | Aim Bow / Rotate grabbed object in Ultrahand |
| **Mouse Wheel** | Zoom camera / Push & pull object with Ultrahand |
| **F** | Activate / Deactivate Ultrahand ability |
| **Q** | Quick Fuse elemental material to weapon |
| **Tab** | Open Inventory / Pause Menu / Adventure Log |

## 🚀 Running the Game Locally

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start the local PC development server**:
   ```bash
   npm run dev
   ```
   The game will automatically launch in your browser at `http://localhost:3000`.

3. **Build for production**:
   ```bash
   npm run build
   ```

4. **Auto-commit & sync to GitHub**:
   ```bash
   npm run sync
   ```
